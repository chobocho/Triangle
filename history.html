Triangle 작업 히스토리

2026-07-22 — Android SDK 37.1 지원

빌드 스크립트가 다른 프로젝트(wordmaster)에서 복사된 상태로 남아 있어 빌드가 불가능했습니다. 복붙 잔재를 정리하고 SDK 37.1(Android 17) 대응을 완료했습니다.

구분내용
SDK / 툴체인 compileSdk를 release(37) { minorApiLevel = 1 }(SDK 37.1)로, targetSdk를 37로 상향.
minSdk 29 → 26 하향.
AGP 9.3.0 / Gradle 9.5.0 / JDK 17로 업그레이드 (기존 Gradle 8.11.1은 신규 compileSdk DSL 미지원).
Java·Kotlin 타깃을 11 → 17로 변경.
버전 카탈로그 누락되어 있던 gradle/libs.versions.toml 신규 작성. 최상위 및 app 모듈 빌드 스크립트가 참조하던 libs.* 별칭을 실제로 해석 가능하게 함.
Kotlin 플러그인 AGP 9는 Kotlin 지원을 내장하므로 별도의 org.jetbrains.kotlin.android 플러그인을 적용하면 kotlin 확장이 중복 등록되어 실패함. 내장 지원만 사용하도록 정리하고 kotlin { compilerOptions { jvmTarget } }으로 대체.
복붙 잔재 제거 namespace가 com.chobocho.wordmaster로 잘못 지정되어 R 클래스가 어긋나던 문제를 com.chobocho.triangle로 복구.
이 앱에서 전혀 쓰지 않는 Apache POI / commons 의존성 4종 제거.
설치 환경에 따라 실패하던 buildToolsVersion 하드코딩 제거.
버전 생성 로직 수정 연도 계산이 20년 어긋나 버전명이 과거로 되돌아가던 문제 수정 (deprecated Date.getYear() → Calendar).
월 표기를 기존 알파벳 체계로 원복.
월 비교가 char와 String이라 항상 불일치해 월별 릴리스 카운트가 매 빌드 초기화되던 문제 수정.
properties 저장이 월 롤오버 처리보다 먼저 실행되던 순서 오류 수정.
파일 스트림을 withInputStream / withWriter로 감싸 누수 제거.
산출물 이름에서 사라졌던 triangle_ 접두어 복구.
테스트 JUnit4 테스트를 쓰면서 useJUnitPlatform()을 켜 두어 테스트가 0개 실행되던 설정 제거.
Edge-to-edge 대응 targetSdk 35+에서는 edge-to-edge가 강제되어 상단 입력창이 상태바에 가려질 수 있음. enableEdgeToEdge() 적용 후 루트 레이아웃에 @+id/main을 부여하고 시스템 바 / 디스플레이 컷아웃 / 키보드(IME) 인셋을 패딩으로 반영.

검증: :app:assembleDebug, :app:testDebugUnitTest, :app:lintDebug 모두 성공. 산출물 triangle_0.1216.ZG4.2-debug.apk 생성 확인.

남은 확인 사항: SDK 36+ 대형 화면에서는 android:screenOrientation="portrait"가 무시되므로 태블릿·가로 모드 레이아웃 검증 필요 (lint LockedOrientationActivity 경고).
